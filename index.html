О проекте Tools Hub

Tools Hub — независимый минималистичный каталог портативных инструментов для анализа и проверки системы Windows, поиска следов активности и работы с реестром.

Архив программ programs.zip подготовлен автором репозитория и загружается напрямую из репозитория GitHub.

Во вкладке «Буферы обмена» собраны заготовки поисковых строк для утилит Everything, Last Activity, System Informer и RegScanner. Содержимое редактируется в файле data/clipboards.json.

Все права на утилиты, товарные знаки и исходный код принадлежат их авторам и разработчикам (Voidtools, PrivaZer, Nir Sofer, System Informer и др.).
